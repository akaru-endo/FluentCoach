# Fluent Coach

A single-file React UI mockup for an AI English coaching experience.

## Source

`FluentCoach.jsx` is a front-end component built with React 18, Tailwind CSS utilities, and `lucide-react`.

The component currently uses local state and dummy data. Replace the `analyzeText` stub in the source file to connect a real language-analysis backend.
